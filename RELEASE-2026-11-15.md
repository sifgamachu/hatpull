# Account deletion and iOS association release — 2026-11-15

The account deletion endpoint now verifies the bearer token with Supabase Auth, deletes only that verified account, uses bounded requests without retries, and returns uncached safe errors. The website no longer unlinks account data before Auth deletion succeeds.

Production migration `20261116030000_account_deletion_cleanup` was applied with explicit owner approval and recorded in migration history. A private BEFORE DELETE trigger atomically removes the deleted user's profile/email preferences and unlinks ownership/membership while preserving celebrations and draws. `hp_account` checks and locks the current confirmed Auth user, preventing an unexpired deleted-user token from recreating a profile. No existing accounts or celebrations were deleted by this migration.
